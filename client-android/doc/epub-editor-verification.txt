EPUB and editor verification / EPUB 與編輯驗證 · 2026-09-27
Version / 版本: 1.0.1 (2), Android 8.0/API 26+

EPUB root cause / EPUB 根因:
Android's Harmony XML factory rejected external-general-entities before
reading container.xml. The earlier desktop-only parser test missed this.
Unsupported optional features now fall back to an empty external-entity
resolver; EPUB 2 NCX/DTDs and EPUB 3 packages can be opened locally.
Android XML 工廠拒絕設定而無法讀取；已改為相容設定及空外部實體解析器。
支援 EPUB 2 NCX／DTD 及 EPUB 3，並更新快取版本以重新建立舊索引。

EpubAndroidTest reproduced the original exception, then passed the fix.
EpubCompatibilityTest covers prefixed XHTML, UTF-16, encoded paths,
chapter order, NCX titles, relative links and SVG cover-image references.
EpubReaderFlowTest imports, paginates and renders the final page in the app.
已重現原始例外並通過修正；涵蓋命名空間、編碼、路徑、章節、連結及圖片。
主機上的實際 Activity 流程驗證了匯入、分頁及最後一頁的文字呈現。
