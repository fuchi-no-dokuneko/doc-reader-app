# Editing · 編輯 · 编辑

Open a programming, configuration or other text file, then tap **Edit source**.
The green **EDIT MODE** screen uses a monospace editor with live syntax colors.
Keywords, strings, numbers, punctuation and comments update as you type.
Code stays verbatim; existing encoding, BOM, indentation and line endings are kept.

**Save** updates the original when Android grants write access. Otherwise it opens
the system picker for an edited copy. **Save a copy** always asks for a destination.
If another app changed the original, save a copy to preserve both versions.
**Read** and Back prompt you to save, discard or keep editing when changes exist.
Rotation retains the current draft. A cancelled picker keeps the draft open.

開啟程式、設定或其他文字檔，點選 **Edit source**。綠色 **EDIT MODE** 畫面
提供等寬編輯器，輸入時即時更新關鍵字、字串、數值、符號及註解的顏色。
保留原始文字、編碼、BOM、縮排與換行，不會自動重新格式化。

**Save** 會在有寫入權限時更新原檔，否則開啟系統選擇器另存副本。
**Save a copy** 一律讓你選擇目的地。若原檔已被其他程式修改，請另存副本。
**Read** 及返回鍵會提示處理未儲存變更；旋轉畫面及取消選擇器均保留草稿。

打开程序、配置或其他文本文件，点击 **Edit source**。绿色 **EDIT MODE** 界面
提供等宽编辑器，输入时即时更新关键字、字符串、数值、符号及注释的颜色。
保留原始文本、编码、BOM、缩进与换行，不会自动重新格式化。

**Save** 会在有写入权限时更新原文件，否则打开系统选择器另存副本。
**Save a copy** 总是让你选择目标位置。若原文件已被其他程序修改，请另存副本。
**Read** 和返回键会提示处理未保存更改；旋转屏幕及取消选择器均保留草稿。
